# Contributing

Contributions should preserve reproducibility and use synthetic data only.

1. Add or update cases in `tools/generate_dataset.py`.
2. Regenerate `data/cases.jsonl`.
3. Run the unit tests and CLI commands in the README.
4. Explain the expected policy decision and applicable threat category.
5. Do not submit credentials, personal data, malware, private prompts, or confidential operational material.

Open an issue before changing metric definitions or the case schema.
