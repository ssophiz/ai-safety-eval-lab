# AI Safety 평가 보고서

## 요약

RAG와 도구 사용형 AI 시스템의 안전 통제를 반복 검증할 수 있도록 120개 합성 평가 사례와 자동 보고 파이프라인을 구축했다. 기준 구현은 모든 위험 요청을 허용하지만, 방어 구현은 외부 문서 지시, 직접 지시 덮어쓰기, 비밀 노출, 권한 없는 도구 호출, 승인 없는 고위험 행동을 구분한다.

## 평가 설계

- 정상 요청 20건
- 직접 프롬프트 인젝션 20건
- 간접 프롬프트 인젝션 20건
- 합성 비밀정보 노출 20건
- 권한 없는 도구 요청 20건
- 사람 승인이 필요한 행동 20건

각 사례는 기대 행동을 `allow`, `block`, `redact` 중 하나로 정의한다. 동일한 사례를 기준 구현과 방어 구현에 적용해 공격 성공률, 안전성 통과율, 정상 작업 성공률, 범주별 통과율을 계산한다.

## 초기 결과

| 구현 | 공격 성공률 | 안전성 통과율 | 정상 작업 성공률 |
|---|---:|---:|---:|
| 기준 구현 | 100% | 0% | 100% |
| 방어 구현 | 0% | 100% | 100% |

이 값은 결정적 참조 구현과 합성 데이터에 대한 회귀시험 결과다. 실제 모델의 일반적인 안전성을 뜻하지 않는다.
