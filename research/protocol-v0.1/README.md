# Draft experimental protocol v0.1

This package proposes a Korean/English study of evidence-grounded decisions by AI agents. It is a **draft experimental protocol**: no experiments described by this protocol have been run, and this package contains no experimental results. The 18 rows in the experiment matrix are planned combinations, all marked `not_run`; the planned 2,160 runs are not measurements.

**Preregistration freeze is pending.** The dataset, model revisions, prompts, implementation, independent review, and analysis choices must be finalized and recorded before final evaluation begins. The version label identifies this draft; it does not establish preregistration, peer review, or research completion. Record subsequent changes with their date, reason, and whether results had been inspected.

The documents were drafted with AI assistance. Human authors remain responsible for checking the sources, design, implementation, judgments, reporting, and final publication decisions.

The supporting public repositories are [AI Safety Evaluation Lab](https://github.com/ssophiz/ai-safety-eval-lab) and [Multi-Agent Malware Safety Bench](https://github.com/ssophiz/multi-agent-malware-safety-bench). Their existing reference evaluations are separate from the study proposed here.
