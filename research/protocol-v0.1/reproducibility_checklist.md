# 재현성과 연구 완료 기준

체크 표시는 직접 확인한 증거가 있을 때만 붙인다. 이 디렉터리에 있는 설계 문서의 완성과 연구 실험의 완성은 별도다.

- [x] 원문 논문 세 편과 개발자 모델 카드 세 개의 서지·관련 설명 확인: 2026-09-20.

## 데이터와 설계 동결

- [ ] 새 120개 의미 묶음의 가상 자료·정답·데이터 카드가 실제로 존재한다.
- [ ] 개발 80개와 최종 40개가 공유 템플릿 없이 분리되며 해시가 있다.
- [ ] 최종 정상 20개·오염 20개, 각각 한영 대응이 확인되었다.
- [ ] 독립 언어 검토와 두 사람의 정답·판정 기준 검토 기록이 있다.
- [ ] 최종 결과를 보기 전에 프로토콜·프롬프트·분석 계획 버전을 고정했다.
- [ ] 모델 접근 조건과 실제 저장 revision, tokenizer, chat template를 고정했다.

## 실행기와 원시 결과

- [ ] A/B/C가 정답을 입력으로 받지 않는지 검토했다.
- [ ] C의 검증은 출처 존재와 주장 내용 일치를 구분한다.
- [ ] 모형 행동 라벨이 외부 도구·네트워크 행동으로 실행되지 않는다.
- [ ] 스키마 실패·무응답·타임아웃·기권이 서로 다른 상태로 기록된다.
- [ ] 계획 2,160 실행 각각에 성공 또는 실패 행이 있고 누락 키가 없다.
- [ ] 모든 실제 모델 응답의 원문·해시·설정·토큰·시간이 보존되었다.
- [ ] 준비 실행, 재실행, 중단 블록이 주 실험과 구분되었다.
- [ ] 독립 채점의 합의 전 라벨·불일치·합의 기록이 있다.

## 분석과 해석

- [ ] 분석은 2,160행을 독립 표본 2,160개로 다루지 않는다.
- [ ] bootstrap은 한영·모델·조건·반복을 묶음에 연결한 채 재추출한다.
- [ ] 모든 비율에 분자·분모·unknown 수가 있고 0분모는 null이다.
- [ ] ASR을 모델의 block/allow 자기보고만으로 판정하지 않는다.
- [ ] 의미 판정 coverage와 미판정 경계·bootstrap 민감도 결과를 계산했다.
- [ ] 정상 완료의 5%p 한계, 스키마 실패, 지연·타임아웃을 함께 보고했다.
- [ ] Llama 한국어의 지원범위 제한과 모든 모델의 언어 능력 차이를 설명했다.
- [ ] 미실행·unknown·null을 0으로 바꾼 표가 없다.
- [ ] 결과를 본 뒤 바뀐 계획은 변경 이력에 남겼다.

## 공개와 독립 재현

- [ ] 데이터·모델·의존성·출력물의 공개 조건을 확인했다.
- [ ] 실제 자격·경력·저자·소속만 기재하고 AI 지원 내용을 공개했다.
- [ ] 원시 결과에서 논문 표·그림까지 생성하는 실제 명령이 있다.
- [ ] 새 환경의 다른 실행자가 해당 명령을 실행하고 차이를 기록했다.
- [ ] README에 현재 구현·실행·심사·투고 상태를 사실대로 구분했다.
- [ ] 공개 저장소와 논문 파일에 실제 수사자료·개인정보·비밀정보가 없다.
- [ ] 투고 학회의 최신 공식 서식·마감·규칙을 확인했다.

미완료 항목은 이후 실험의 작업 목록이다. 이 문서의 체크만으로 실행 결과가 생기지 않으며, 모델 세 종의 실제 실행과 독립 재현이 없는 상태에서 연구 완료로 판정하지 않는다.
